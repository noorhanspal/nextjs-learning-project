# Next.js Learning Project 🚀

This is a modern multi-page web application built using Next.js while learning the App Router, nested routing, layouts, and reusable components.

## 📌 Features

- App Router (Next.js 13+)
- Nested Routing (user/service pages)
- Reusable Components (Navigation, Cards)
- Responsive Team/Service Page Layout
- Clean UI with modern styling

## 🛠️ Technologies Used

- Next.js
- React
- JavaScript
- CSS
